# 三步完成定时任务（GitHub，与热点板块一致）

## 第 1 步：GitHub 仓库 + push

1. 浏览器打开：<https://github.com/new?name=guijinshu-waihui-zhoubao>（Owner 选 **cmm1022**）
2. 选 **Private**，**不要**勾选 “Add a README”
3. 点 **Create repository**
4. 在本机终端执行：

```powershell
cd "D:\cursor项目\贵金属外汇周报"
git remote set-url origin https://github.com/cmm1022/guijinshu-waihui-zhoubao.git
git branch -M main
git push -u origin main
```

登录 GitHub 授权后，看到 `main -> main` 即可。

若出现 `Connection was reset` / 无法连接 443：本机需开代理（如 Clash **7890**）。本仓库已配置 `git config --local http.proxy`；或执行 `powershell -File scripts\git_push.ps1`。

## 第 2 步：Automation Secrets

1. Cursor → **Automations** → 打开「周报邮件抓取并发布 CMS」
2. **Secrets** 中按 [automation-secrets.md](automation-secrets.md) 添加变量
3. 终端可运行辅助脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\copy_secrets_for_automation.ps1
```
