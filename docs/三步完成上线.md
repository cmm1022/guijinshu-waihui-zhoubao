# 三步完成定时任务（跟着做即可）

## 第 1 步：创建在线仓库（约 2 分钟）

1. 浏览器打开：<https://cursor.com/codebase/get-started>（若已打开可跳过）
2. 用 **Cursor 账号登录**（与 Cursor 编辑器同一账号）
3. 点击 **New repository** / **创建仓库**
4. 名称填：`guijinshu-waihui-zhoubao`（被占用就加后缀）
5. 创建成功后，找到 **Clone** → 复制 **HTTPS** 地址（以 `https://origin.cursor.com/` 开头）
6. **回到 Cursor 对话**，把复制的地址 **整段粘贴发给 AI**，写：「远程地址是 xxx」

AI 会在你电脑上执行 push，无需你再敲命令。

---

## 第 2 步：填 Automation 密钥（约 3 分钟）

1. 在 Cursor 里打开 **Automations**（左侧或设置里）
2. 打开自动化 **「周报邮件抓取并发布 CMS」**（若还没有，点 New，名称同上）
3. 找到 **Secrets**（密钥）区域，点 **Add secret**
4. 在 Cursor **终端**（PowerShell）执行：

```powershell
cd "D:\cursor项目\贵金属外汇周报"
powershell -ExecutionPolicy Bypass -File .\scripts\copy_secrets_for_automation.ps1
```

5. 脚本每提示一个变量名（如 `EMAIL_USER`）：
   - 在 Automations → Secrets 里 **Name** 填同名
   - **Value** 在终端按 **Enter** 后 **Ctrl+V 粘贴**
   - 保存该条，再回到终端按 Enter 下一条
6. 全部填完后关闭脚本（或 Ctrl+C）

---

## 第 3 步：保存自动化

在同一 Automation 页面：

1. **Repository**：选 `guijinshu-waihui-zhoubao`（第 1 步 push 成功后会出现）
2. **Schedule**：每周一 **9:00**，时区选 **Asia/Shanghai** 或界面上的 **北京时间**
3. 确认 Agent 指令里包含 `python -m src.run_weekly`
4. 点 **Save**

完成。下周一 9:00 会自动跑；也可点 **Run now** 试跑一次。

---

## 遇到问题

| 现象 | 处理 |
|------|------|
| push 要登录 | 浏览器用 Cursor 账号登录后再 push |
| 列表里没有 msedge | Secrets 里设 `CMS_BROWSER_CHANNEL=chromium`，指令里用 `playwright install chromium` |
| 只想试跑不真发 | Secrets 临时加 `CMS_DRY_RUN=1` |
