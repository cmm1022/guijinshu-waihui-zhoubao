# 一键配置 Cloud Secrets（你只需粘贴一次 API Key）

Secrets **不在** Automations 页面，而在 **Cloud Agents → 环境 → Secrets**。  
已提供脚本自动写入，无需在网页里逐条 Add secret。

## 只做一次（约 2 分钟）

1. 在 Cursor 终端执行：

```powershell
cd "D:\cursor项目\贵金属外汇周报"
powershell -ExecutionPolicy Bypass -File .\scripts\setup_cloud_complete.ps1
```

2. 浏览器会打开 **Settings**；在 **API Keys** 里 **Create**，复制密钥。  
3. 回到终端，**粘贴 API Key**，Enter。  
4. 脚本会：
   - 创建/找到 Cloud 环境 `guijinshu-waihui-zhoubao`
   - 把 `.env` 里邮件/CMS、**分租户**（`CMS_TENANT_*`、`CMS_TENANT_PUBLISHERS`）等变量写入该环境的 **Runtime Secrets**
   - 打开 Automations 页面  

5. 在 Automation「周报邮件抓取并发布 CMS」中：
   - **Environment** 选 `guijinshu-waihui-zhoubao`
   - **Repository** `cmm1022/guijinshu-waihui-zhoubao` / `main`
   - **Save**

## 可选：不用交互脚本

在 `.env` 增加 `CURSOR_API_KEY=...` 后：

```powershell
python scripts/sync_cursor_cloud_secrets.py
```

## 说明

- API Key 仅用于配置，**不要提交 Git**（`.env` 已在 `.gitignore`）。
- 云端 Playwright 已在 `.cursor/environment.json` 的 `install` 里配置为 `chromium`。
