# 分租户发布（推荐）

同花顺运营账号上的「内容同步」依赖 SaaS 后台把文章推到其他租户，**经常出现编辑页为空或部分租户收不到**。更稳妥的做法是：**用各租户自己的 CMS 账号分别登录、各发一篇**，不依赖「内容同步」。

## 配置步骤

1. 在 `.env` 或 Cursor Cloud **Environment Secrets** 中增加租户密码（**不要写进 Git、不要贴在聊天里**），例如：

   - `CMS_TENANT_ZRCUB_PASSWORD` — 浙江省联社  
   - `CMS_TENANT_PSBC_PASSWORD` — 邮储银行  
   - `CMS_TENANT_HZBANK_PASSWORD` — 杭州银行  
   - `CMS_TENANT_BOCOM1_PASSWORD` / `CMS_TENANT_BOCOM2_PASSWORD` — 两个交通银行租户  

2. 增加一行 JSON（邮箱换成各租户真实登录邮箱）：

```env
CMS_TENANT_PUBLISHERS=[{"name":"浙江省联社","keywords":["贵金属周报"],"email":"租户邮箱","password_env":"CMS_TENANT_ZRCUB_PASSWORD"},{"name":"邮储银行","keywords":["贵金属周报"],"email":"租户邮箱","password_env":"CMS_TENANT_PSBC_PASSWORD"},{"name":"杭州银行","keywords":["贵金属周报"],"email":"租户邮箱","password_env":"CMS_TENANT_HZBANK_PASSWORD"},{"name":"交通银行-1","keywords":["外汇周报"],"email":"租户邮箱","password_env":"CMS_TENANT_BOCOM1_PASSWORD"},{"name":"交通银行-2","keywords":["外汇周报"],"email":"租户邮箱","password_env":"CMS_TENANT_BOCOM2_PASSWORD"}]
```

3. （可选）显式指定模式：

```env
CMS_PUBLISH_MODE=per_tenant
```

配置了 `CMS_TENANT_PUBLISHERS` 且未设置 `CMS_FORCE_OPERATOR_SYNC=1` 时，**默认即为分租户发布**，不再只用 `CMS_EMAIL` 发一篇。

4. 若仍想只用运营账号 + 内容同步（不推荐），设置：

```env
CMS_FORCE_OPERATOR_SYNC=1
CMS_EMAIL=...
CMS_PASSWORD=...
```

## 行为说明

| 模式 | 行为 |
|------|------|
| `per_tenant` | 每篇周报对 `keywords` 匹配的租户**各登录一次**，各发一篇，**不勾选内容同步** |
| `operator_sync` | 仅 `CMS_EMAIL` 登录，勾选内容同步 + 发布接口兜底 |

外汇需要**两个不同的交通银行租户账号**（下拉中往往只有一个「交通银行」选项，无法在同一账号里选两次）。

## 本地试跑

```powershell
$env:CMS_DRY_RUN='1'
python -m src.run_weekly
```

确认日志里租户列表正确后，再去掉 `CMS_DRY_RUN` 正式发布。
